## What Went Well

- **The test suite kept climbing with zero regressions** across all 5 stories, continuing the streak from Epic 10/11.
- **The `tsc --noEmit` silent-no-op lesson actually stuck.** Story 12.1 discovered mid-epic that `client/tsconfig.json`'s `"files": []` makes `npx tsc --noEmit` check zero files — a false-negative "clean" that let a real type error reach `main` and fail the deploy job. Every subsequent story (12.2, 12.3, 12.4, 12.5) explicitly cited the correction and used `tsc -b` instead. Unlike some past lessons, this one propagated and held for the rest of the epic.
- **Adversarial code review kept catching real, non-cosmetic bugs.** Story 12.2's review caught a duplicate-ID payload that would corrupt assignment-period data and crash every subsequent save with an unhandled exception, plus a Smart-Strip double-counting bug — and then, while implementing the fix for the double-counting bug, the dev agent traced a *second*, previously undetected double-count bug hiding in the pre-existing orphaned-plug fallback. Confirmed empirically: the existing regression test's own seeded data had been silently producing `16` instead of the correct `11` the whole time.
- **The live production bug (Reading History overflow) got investigated and fixed same-day**, mirroring Epic 11's `bmad-correct-course` pattern for 11.13/11.14 — though this one didn't become a formal story, just a direct investigation + fix commit.

## Challenges & Patterns

- **"Gap found during story creation" produced the largest unplanned rework yet.** Story 12.2 found four material gaps in the epic's own text — `Flat.CreatedAt` doesn't exist, the epic's literal AC3 was flatly impossible without first reworking `UpdateFlatStructureFunction` into a full identity-preserving upsert (which became, in its own words, "this story's real center of gravity"), a third recurrence of the exact nullable-FK-cascade-path issue Epic 10's Action Item #2 exists to catch, and the decimal-rounding fold-in hand-off from 12.1. **Resolution reached this retro:** rather than accept this as pure "process working as intended" (last retro's verdict for smaller gaps), the team agreed to add a step at epic-authoring time — verify any AC that assumes a specific backend mechanism already exists (e.g., "the system can recognize this is the same entity") against the actual current code, so an epic-invalidating gap this size surfaces before hand-off, not mid-story.
- **Two Epic 10/11 carried-forward action items are now 0-for-3 epics** — Winston's durable FK-cascade-path architecture-review checklist and Murat's test-naming-vs-assertion tightening in `dev-story` never became real artifacts across Epic 10, 11, or 12, even though the cascade-path issue itself recurred a third time in Story 12.2 (and was caught correctly again, by awareness alone). **Resolution:** stop carrying these as informal retro action items — both become real, ownable stories in Epic 13 planning instead.
- **`deferred-work.md` hygiene continues to lose ground.** 75 open sections at Epic 11's retro (7 closed) → 81 sections now (only 3 marked closed total). Individual stories keep closing only their own directly-relevant entries; nothing closes the gap systemically. Named again, no new action taken — watching for a threshold before treating this as urgent.
- **Story 12.2's big upsert rework got close to Epic 13's exact bug class but didn't close it.** Making Room/PowerPoint/Device row identity survive a save (for `DeviceAssignmentPeriod` integrity) is a different fix from "nothing absent from a stale payload gets deleted" — the latter is the actual root cause behind Epic 13's confirmed data-loss investigation, which surfaced independently days after 12.2 shipped.
